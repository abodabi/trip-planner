# תקציב הטיול לטטרה — הקמה ופריסה

מדריך צעד-אחר-צעד להקמת האתר העצמאי עם התחברות גוגל. יש Node.js אצלך, אז אפשר להתחיל ישר משלב 2.

## שלב 1: חשבון גוגל אישי
ודא שיש לך חשבון Gmail אישי (לא חשבון עבודה/ארגון). אם אין — צור אחד בחינם ב-https://accounts.google.com/signup (2 דקות).

## שלב 2: יצירת פרויקט Firebase
1. גש ל-https://console.firebase.google.com
2. "Add project" → תן שם (למשל `tatra-trip-planner`) → המשך עם ברירות המחדל
3. בתוך הפרויקט: לחץ על סמל ה-`</>` (Web app) כדי להוסיף אפליקציית ווב
4. תן לה כינוי (למשל `tatra-web`), **אל תסמן** "Firebase Hosting" בשלב הזה
5. תקבל בלוק קוד עם `firebaseConfig = {...}` — **העתק את זה**

## שלב 3: הפעלת התחברות עם גוגל
1. בתפריט הצד: **Build → Authentication → Get started**
2. בלשונית **Sign-in method**, הפעל את **Google**
3. שמור

## שלב 4: יצירת מסד נתונים Firestore
1. בתפריט הצד: **Build → Firestore Database → Create database**
2. בחר מיקום קרוב (למשל `eur3` אירופה) → **Start in production mode**

## שלב 5: הגדרות מקומיות
1. העתק את `.env.example` לקובץ חדש בשם `.env.local`
2. מלא בו את הערכים מה-`firebaseConfig` שהעתקת בשלב 2 (הקובץ הזה לא נכנס לגיט)

**הרשאות גישה**: אין צורך בהגדרה ידנית. כל מי שמתחבר עם גוגל יכול ליצור טיולים משלו; כל טיול פרטי למשתתפיו. שיתוף נעשה מתוך האפליקציה — הגדרות הטיול ⚙ → הוספת מייל → שמירה, ואפשר גם לשלוח את הקישור הישיר לטיול (עובד רק למשתתפים). ההגנה האמיתית היא ב-`firestore.rules`, שבודקים חברות ברשימת `memberEmails` של כל מסמך טיול.

## שלב 6: התקנה והרצה מקומית (לבדיקה)
```bash
npm install
npm run dev
```
פתח את הכתובת שמוצגת (בדרך כלל `http://localhost:5173`) ונסה להתחבר עם גוגל — ודא שזה עובד לפני שממשיכים.

## שלב 7: התקנת כלי הפריסה של Firebase
```bash
npm install -g firebase-tools
firebase login
```
זה יפתח דפדפן להתחברות לחשבון הגוגל שלך.

## שלב 8: קישור הפרויקט
```bash
firebase use --add
```
בחר את הפרויקט שיצרת בשלב 2.

## שלב 9: פריסת חוקי האבטחה
```bash
firebase deploy --only firestore:rules
```

## שלב 10: בנייה ופריסה של האתר
```bash
npm run build
firebase deploy --only hosting
```
בסיום תקבל כתובת אתר אמיתית (משהו כמו `https://tatra-trip-planner.web.app`) — זו הכתובת לשלוח לאשתך.

## עדכונים עתידיים
בכל פעם שתרצה לעדכן את האתר (שינוי עיצוב, פיצ'ר חדש וכו'):
```bash
npm run build
firebase deploy --only hosting
```

## פתרון בעיות נפוצות
- **קישור לטיול מחזיר למסך הטיולים**: המייל שאיתו התחברת אינו ברשימת המשתתפים של הטיול. בקש ממשתתף קיים להוסיף אותך בהגדרות הטיול (בדיוק אותו מייל, אותיות קטנות/גדולות).
- **מסך לבן אחרי הפריסה**: פתח את קונסולת הדפדפן (F12 → Console) ותבדוק שגיאות. לרוב זה ערכים חסרים ב-`.env.local` (יש לבנות מחדש אחרי שינוי בו).
- **שינויים לא נשמרים בין מכשירים**: ודא ששני הצדדים מחוברים עם מיילים שמופיעים במשתתפי הטיול (הגדרות ⚙).
